# Ресторан «Booking Table»

Полнофункциональное Django-приложение для управления бронированием столиков в ресторане. Проект включает адаптивный интерфейс на Bootstrap, личный кабинет для пользователей и админ-панель Django для управления контентом и бронями.

## Возможности

- Главная страница с информацией о ресторане, перечнем услуг, командой и формой обратной связи.
- Страница «О ресторане» с историей и ценностями команды.
- Полный сценарий бронирования с фильтрацией по доступности и управлением заявками.
- Личный кабинет с историей бронирований и редактированием профиля.
- Админка Django для управления столиками, бронированиями, текстами и сообщениями.
- Среда разработки в Docker с PostgreSQL.

## Технологический стек

- Python 3.12, Django 5
- PostgreSQL (драйвер `psycopg`)
- Bootstrap 5
- Docker и Docker Compose

## Как начать работу

### Предварительные требования

- Python 3.12+
- PostgreSQL 15+
- (опционально) Docker и Docker Compose v2

### Переменные окружения

Создайте файл `.env` на основе подготовленного шаблона:

```bash
cp .env_sample .env
```

Заполните значения безопасными данными. Основные переменные:

- `SECRET_KEY`
- `DB_NAME`
- `DB_USER`
- `DB_PASSWORD`
- `DB_HOST`
- `DB_PORT`

### Локальный запуск без Docker

Установите зависимости и выполните миграции:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт будет доступен по адресу `http://127.0.0.1:8000/`. Админ-панель — `http://127.0.0.1:8000/admin/`.

### Работа через Docker

Соберите и запустите сервисы:

```bash
docker compose up --build
```

Команда поднимет Django-приложение и PostgreSQL. Выполните миграции и создайте суперпользователя внутри контейнера:

```bash
docker compose exec web python manage.py migrate
docker compose exec web python manage.py createsuperuser
```

### Тестирование

```bash
python manage.py test
```

## Управление через админку

Через Django admin можно управлять:

- **Информацией о ресторане**: названиями, описанием, контактами и миссией.
- **Услугами**: блоками, отображаемыми на главной странице.
- **Командой**: сотрудниками на главной и странице «О ресторане».
- **Столиками и бронированиями**: контролировать доступность, подтверждать и отменять заявки.
- **Сообщениями с сайта**: просматривать обращения из формы обратной связи.
